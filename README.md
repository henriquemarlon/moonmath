# MoonMath with SageMath

zk studies.

## Start

Requires Docker Desktop running, Docker Compose, and Git. SageMath 10.9 and Jupyter run in a Conda environment built for native ARM64 / Apple Silicon.

```sh
docker compose up -d --build
```

Open [localhost:8888](http://127.0.0.1:8888) and enter the token shown in the logs.
